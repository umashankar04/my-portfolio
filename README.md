# Umashankar Portfolio Website

Personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Publish to GitHub Pages

1. Create a GitHub repository named `my-portfolio` under account `umashankar04`.
2. Push this project to the `main` branch.
3. Run:

```bash
npm run deploy
```

4. In GitHub repo settings, ensure Pages is set to deploy from branch `gh-pages`.

Published URL:

`https://umashankar04.github.io/my-portfolio`
